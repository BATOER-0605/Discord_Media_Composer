# Discord Media Composer

スマホで撮影した動画・写真を、Discord のメディアアップロード上限（10MB）以下に
**サーバー側で圧縮**する Web アプリです。圧縮済みファイルをダウンロードして、手動で
Discord に共有できます。

- 📱 スマホのブラウザからそのまま使える（カメラ起動にも対応）
- 🗜️ 動画は ffmpeg の 2-pass エンコードで目標サイズに収め、写真は JPEG 品質を自動調整
- 🔒 処理したファイルは**セッション終了時に完全破棄**（猶予期間内なら処理に再アタッチ可能）
- 🐳 `docker compose up -d` だけで起動（設定ファイル不要）

## クイックスタート（Docker）

```bash
git clone <this-repo>
cd Discord_Media_Composer
docker compose up -d
```

ブラウザで `http://<サーバのIP>:3000` を開くだけです。`.env` などの作成は不要で、
サーバに割り当てられた全 IP アドレスからアクセスできます。

停止・削除:

```bash
docker compose down
```

## ローカル開発（Node.js 22）

```bash
npm install
npm run dev        # http://localhost:3000 （ファイル変更を監視）
# または
npm start
```

システムに ffmpeg が無くても動作します（`ffmpeg-static` / `ffprobe-static` を同梱）。

## 使い方

1. ページを開き、写真または動画を選択
2. 「圧縮する」をタップ
3. 進捗バーが 100% になったら「ダウンロード」
4. 保存したファイルを Discord に共有

## 仕組み

- アップロードすると即座に `jobId` を返し、圧縮はバックグラウンドで実行します。
  クライアントは状態をポーリングし、完了後にダウンロードします。
- **動画**: ffprobe で長さを取得し、目標サイズから動画ビットレートを逆算。
  低すぎる場合は解像度を 1080→720→480→360 と段階的に下げ、2-pass で目標サイズに収めます。
  収まらなかった場合は実測値から 1 度だけ補正エンコードします。長すぎて圧縮不能な動画は
  トリミングの目安を提示します。
- **画像**: EXIF の向きを反映しつつ、JPEG 品質を二分探索。大きすぎる場合は長辺を縮小します。

## データの寿命とセッション

- ブラウザを開いている間はハートビートでセッションが維持されます。
- 切断後、**猶予期間（既定 5 分）**を超えるとセッション終了とみなし、進行中の圧縮を
  完了を待たずに停止し、生成物を含む一時ファイルを完全に削除します。
- 猶予期間内に再アクセスすれば、裏で継続していた処理にそのまま再アタッチできます。
- Docker では `uploads` / `outputs` を tmpfs にマウントするため、ホストにファイルは残りません。

## 設定（任意）

すべての項目に既定値があり、設定なしで動作します。上書きしたい場合は `.env.example` を
`.env` にコピーして編集するか、`docker-compose.yml` の `environment` に渡してください。

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | `3000` | 待受ポート |
| `HOST` | `0.0.0.0` | バインドアドレス（全 IP からアクセス可） |
| `SESSION_SECRET` | 自動生成 | Cookie 署名鍵。空なら起動時にランダム生成 |
| `TARGET_MB` | `9.5` | 目標ファイルサイズ（MB） |
| `MAX_UPLOAD_MB` | `500` | アップロード上限（MB） |
| `AUDIO_BITRATE_K` | `128` | 音声ビットレート（kbps） |
| `MIN_VIDEO_BITRATE_K` | `145` | これを下回るなら解像度を下げる（kbps） |
| `X264_PRESET` | `medium` | x264 プリセット |
| `GRACE_PERIOD_MINUTES` | `5` | セッション終了までの猶予期間（分） |
| `MAX_CONCURRENT_JOBS` | `2` | 同時圧縮ジョブ数 |

## 対応形式

- 画像: JPEG / PNG / WebP / HEIC・HEIF
- 動画: MP4 / MOV(QuickTime) / MKV / WebM / 3GP

> HEIC/HEIF は環境の libvips が libheif を含む場合に対応します。デコードできない場合は
> iPhone の「設定 → カメラ → フォーマット → 互換性優先」で JPEG 撮影に切り替えてください。
